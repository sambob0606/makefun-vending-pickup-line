A Python program that writes one original one-line pickup line, spoken by a vending machine to a passing human, for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun.

The line:

> Excuse me, I don't say this to everyone — but you pressed all my buttons, and I didn't even ask for exact change.

## Run it

```sh
python3 main.py
```

It writes the line (113 characters, one line) to `/output/entry.txt`.
